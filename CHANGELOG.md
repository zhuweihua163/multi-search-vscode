# Change Log

All notable changes to the "multi-search-vscode" extension will be documented in this file.

<!-- Check [Keep a Changelog](https://keepachangelog.com/) for recommendations on how to structure this file. -->


## [1.0.3]

- Refresh search results when matched lines change.
- Clear stale results when a file search has no matches.

## [1.0.2]

- Include unsaved changes in global search results.
- Respect `search.exclude` settings in global search.

## [1.0.1]

- Respect `files.exclude` settings in searches.
- Refresh file-search results while editing unsaved documents.
- Fix opening file-search results with Windows paths.
- Improve the release workflow with manual runs and VSIX artifact packaging.

## [1.0.0]

- Initial release
